代肝管家 · 使用说明
====================

一、怎么打开
  双击本文件夹里的「代肝管家.exe」即可，不需要安装任何东西（程序自带运行环境，约 134MB 的文件夹请整体保留）。
  建议：右键 exe → 发送到 → 桌面快捷方式，以后从桌面打开。

二、第一次打开
  程序会自动从旧工具里读取历史数据：
    · F:\鸣潮\bills 下的旧账单（16 条订单）
    · F:\鸣潮\tools\日期记载\data.db 里的旧托管记录（2 条 + 99 次打卡）
  导入完成后会弹窗告诉你导入了多少条，旧工具可以继续留着，不影响。

三、七个页面在做什么
  1. 概览       今天做了几单、赚了多少、我/助手/跑手各分多少；近 7 天营业额曲线；待办提醒；本月经营。
  2. 订单管理   所有订单的表格。新增订单、双击改单、右键改状态、删除、按日期/状态筛选、搜索、导出 CSV。
  3. 托管日历   包月托管订单的打卡月历。点某一天即可打卡/取消打卡，右侧显示本月打卡进度。
  4. 统计报表   按年查看：每月单数/营业额/我的分成/助手分成/跑手分成，以及按项目、按跑手的占比。
  5. 跑手管理   跑手名单与分成比例（小予默认 85%）。
  6. 价目表     托管/任务/地图满探索三类价格清单，新增订单时可直接选项目自动带出金额。
  7. 设置       店铺名、你的称呼、11 项分成规则（比例与规则生效日期）、数据备份、导出全部订单。

四、数据存在哪里（重要）
  全部数据都在本文件夹下的 data 目录里（data\app.db），只存在这台电脑上，不会联网。
  · 备份：复制整个 data 文件夹到别处（U 盘/网盘）即可；恢复时把它放回原处。
  · 设置页里的「备份数据库」也会把 app.db 复制一份到你选择的位置。
  · 换电脑：把整个「发布」文件夹拷过去就能用，数据跟着走。

五、分成规则（默认与你以前的算法一致）
  · 个人接单：金额 > 100 用高比例、否则用低比例
      - 2026-06-24 之前的单：高 40% / 低 20%
      - 2026-06-24 及之后的单：高 20% / 低 10%
  · 非个人单：跑手 80%，助手 15%，我的 5%
  · 跑手「小予」的单：跑手 85%（我 15%，助手 0）
  · 全部比例都能在「设置」里改，改完保存，报表会立即按新规则重算。

六、遇到问题
  程序根目录会生成「错误日志.txt」，把里面的内容发我即可定位。

【2026-10-29 第三批更新】
· 修复「新增的托管订单不出现在托管日历里」：新增 / 编辑订单时选到「包月」「托管服务」这类项目，会自动把「托管开始日期」填成订单日期、「托管结束日期」填成一个月后，可以自己改。

· 如果某单确实不需要打卡（比如一次性代肝），日期留空就好，不影响其他功能。

【2026-10-29 第四批更新：流畅度与外观】
· 新增「外观」设置（设置页 → 外观）：
  · 选择图片：给窗口换一张背景图（支持 jpg / png / bmp），图片会复制到 数据目录\images 里，换电脑时跟着数据一起走。
  · 遮罩浓度：0~100，数值越大背景越淡、文字越清楚（默认 78）。
  · 图片铺法：填满 / 完整显示 / 拉伸 / 平铺。
  · 模糊程度：0~30，把背景虚化一点，透过卡片看见也更柔和。
  · 恢复默认外观：一键回到纯色浅色界面。
· 卡片改成半透明，换背景图后能透出一点背景，但不影响看字。
· 操作后有底部提示条：保存订单 / 删除订单 / 改状态 / 已打卡 / 已导出 / 已刷新 等都会在下方轻提示一下，不再弹对话框打断操作。
· 流畅度：
  · 切换页面时淡入 + 轻微上浮，不再"啪"地整块换掉；
  · 鼠标滚轮改为短距离缓动滚动，长列表更跟手；
  · 订单表格只渲染可见行，几百单也不卡；
  · 启动时窗口淡入；Windows 11 下窗口四角跟随系统圆角。
· 新增快捷键（设置页「快捷键」卡片里也有列出）：
  · Ctrl + 1 ~ 7：切换 概览 / 订单 / 日历 / 报表 / 跑手 / 价目 / 设置
  · Ctrl + N：直接新增订单
  · Ctrl + F：定位到订单搜索框
  · F5：刷新当前页
  · Esc：关闭当前弹窗
  · Ctrl + S：在新增/编辑订单窗口里保存

【2026-10-29 第五批更新：切页更跟手】
· 页面只创建一次，切回来直接复用：不再每次切页都重新读数据库、重新排表格；
· 启动后会在空闲时间把其它页面悄悄准备好，第一次点开也不卡；
· 切页动画改轻了（只做很小的一段上浮，不再整页淡入淡出）；
· 卡片阴影换成 1px 细描边，观感更清爽，渲染也更快；
· 连点导航（两次切换间隔 < 0.3 秒）会自动跳过动画，手感更"跟手"。
· 实测（发布版）：来回切换一页的耗时从原来的几十~上百毫秒降到 0~10 毫秒。

【2026-10-29 第六批更新：可以用壁纸引擎的壁纸当背景了】
- 设置 → 壁纸（Wallpaper Engine）：会把本机订阅的壁纸列出来（缩略图 + 标题 + 类型），点一张就立刻换成窗口背景。
- 「跟随 Wallpaper Engine 当前壁纸」：勾上后，每次切回本窗口自动用你在壁纸引擎里正在用的那张。
- 视频壁纸会静音循环播放；视频不支持模糊，但可以调「遮罩浓度」让文字更清楚。
- 原来的「外观 → 选择图片」还能用，两套来源（静态图片 / 订阅壁纸）可以随时切换。
- 说明：壁纸引擎没有公开的"账号订阅"接口，这里是直接读本机 Steam 创意工坊目录（如 F:\steam\steamapps\workshop\content\431960），所以换电脑后需要重新订阅下载壁纸才会出现在列表里。
【2026-10-29 第七批更新：壁纸通透模式】
1. 设置 → 外观 里多了「通透模式（只留文字与组件轮廓）」。开启后卡片、侧栏、输入框、表格分隔线都变成半透明白，
   壁纸整块透出来，界面上只剩文字和 1px 的轮廓线；换壁纸时会自动帮你打开。
2. 壁纸清晰度：视频类壁纸直接播放原片，最清晰；场景 / 网页类壁纸优先用作品目录里最大的那张预览图
   （一般是 1024px，比 192px 的缩略图清楚很多），Steam 上有更大图时会自动缓存到 data\images\we 目录。
3. 觉得文字不够清楚，把「遮罩浓度」往右调（数值越大壁纸越淡、文字越清楚）；想看壁纸就把浓度调小。

【2026-10-29 第八批更新：托管订单可以续单了】
1. 订单管理页工具栏多了「续单」按钮（右键菜单也有「续单（托管）」），选中一条托管订单后点它：
   选续几个月（1/2/3/6/12），按需填「本月追加金额」和备注，确认后托管结束日期直接往后顺延。
2. 续单窗口会实时预览「续单后的托管期」和「续单后的订单金额」，按 Ctrl+Enter 或点「确认续单」保存，Esc 取消。
3. 续单成功后：订单备注会自动追加「续单 +N 个月（至 年-月-日）」，托管日历立刻按新的结束日期显示。
4. 只能给「托管订单」续单（没填托管开始/结束日期的一次性代肝单会自动禁用该按钮）。

【2026-10-29 第九批更新：场景壁纸不再糊了（会按窗口大小真渲染）】
1. 场景（scene）类壁纸以前只能用 254~1079px 的封面图，放大就糊；现在切到场景壁纸时，程序会解析它的 scene.pkg
   真渲染一张和窗口像素一样大的图（首次约 1~3 秒，期间先显示封面，底部有「正在生成高清壁纸…」提示）。
2. 渲染结果缓存在 data\images\scene\<ID>_<宽>x<高>.jpg，下次打开同一张就是秒开。
3. 自适应：窗口拉大（比如最大化）会自动按新尺寸重渲染一张更清楚的，缩小则复用已有的大图。
4. 电脑里有 ffmpeg 的话，带内嵌视频贴图的场景也能正确出图；没有也能渲染，只是极少数场景会缺一层动态背景。
5. 已知限制：场景里的粒子、文字、bloom 等后处理以及三维模型场景还原不完整（这类壁纸可能比原版朴素一点），
   视频壁纸和普通图片壁纸不受影响。

【2026-10-29 第十批更新：动态壁纸（实验）+ 开机自动启动】

1. 动态壁纸：设置 → 外观 → 勾上「动态壁纸（实验）」。
   - 场景类壁纸会在后台逐帧渲染：雪、雨、落叶、火花、萤火、花瓣、气泡等粒子会动起来，
     壁纸自带的关键帧动画（图层平移/旋转/缩放）也会播放。
   - 默认关闭。开启后静止画面约占 1% CPU，带关键帧动画的壁纸会用到接近一个核心。
   - 视频壁纸本来就在播放，不受这个开关影响。
   - 局限：粒子是按预设名"近似"的，认不出的自定义粒子照旧不画；文字层、脚本、
     bloom 等后处理仍然没有，所以和 Wallpaper Engine 原版观感还有差距。

2. 开机自动启动：设置 → 启动 → 勾上「开机自动启动」。
   - 写在当前用户注册表 HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run，
     不需要管理员权限；去掉勾即关闭。

3. 其它：高清渲染上限从 2600 提到 3840（4K 屏也不再糊）；缓存会自动清理
   （同一张壁纸最多留 3 个尺寸，30 天没用过的自动删）。

【2026-10-30 补充：开机自启的兼容处理】
这台电脑的 Windows 会话不允许程序写「Run 注册表项」和「启动文件夹」，所以设置 → 启动 里的「开机自动启动」会自动改用「计划任务（登录时触发）」的方式，效果一样：登录 Windows 后自动打开代肝管家。
现在已经帮你把「代肝管家」计划任务建好了（任务计划程序里能看到，状态 Ready）。想关掉就把设置里的勾去掉。
